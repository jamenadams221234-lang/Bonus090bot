# 🤖 AI Grammar Corrector + 🔊 TTS Bot

Telegram bot that corrects grammar and converts text to speech.

## Features
- ✍️ Grammar correction (LanguageTool)
- 🔊 Text-to-speech (gTTS → voice message)
- ⚡️ Fast, simple, easy

## Commands
| Command | Description |
|---|---|
| `/start` | Welcome message |
| `/help` | Help menu |
| `/tts <text>` | Convert text to voice |
| `/voice` | Reply to a message → hear it |

## Deploy on Railway
1. Push this repo to GitHub
2. Create a new project on [Railway](https://railway.app) → "Deploy from GitHub"
3. Add environment variable `BOT_TOKEN`
4. Deploy ✅
